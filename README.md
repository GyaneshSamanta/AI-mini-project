# AI Mini Project: Spam SMS Classification

An end-to-end machine learning project designed to classify SMS messages as either "Spam" or "Ham" (legitimate) using natural language processing (NLP) and supervised learning.

## Features

- **Text Preprocessing**: Tokenization, stop-word removal, and lemmatization.
- **Feature Engineering**: TF-IDF Vectorization or Count Vectorization.
- **Model Evaluation**: Comprehensive analysis of multiple classifiers (Naive Bayes, Random Forest, SVM).
- **Interactive Notebook**: Detailed, step-by-step walkthrough in `Spam SMS Classication.ipynb`.

## Technologies Used

- Python 3.x
- Scikit-learn, Pandas, NLTK, Matplotlib, Seaborn

## Use Case

Can be integrated into messaging platforms to automatically filter unwanted advertising or malicious content.
