# AI Mini Project: Spam SMS Classification

An end-to-end machine learning project designed to classify SMS messages as either "Spam" or "Ham" (legitimate) using natural language processing (NLP) and supervised learning.

## Features

- **Text Preprocessing**: Tokenization, stop-word removal, and lemmatization.
- **Feature Engineering**: TF-IDF Vectorization or Count Vectorization to convert text into numerical data.
- **Classification Model**: Comprehensive evaluation of various classifiers (SVM, Naive Bayes, Random Forest).
- **Interactive Notebook**: Detailed step-by-step walkthrough in the provided Jupyter Notebook.

## Dataset

The project uses a standard SMS Spam dataset containing labeled examples of legitimate and spam messages.

## Usage

1. Open `Spam SMS Classification.ipynb` in a Jupyter environment.
2. Install necessary libraries: `pip install pandas scikit-learn nltk seaborn`.
3. Run the cells to train and evaluate the model.
